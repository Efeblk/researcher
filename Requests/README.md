# HTTP istek yüzeyleri

İki servis kendi HTTP yüzeyine ve çalıştırılabilir örneklerine sahiptir:

- [Academic Collector örnekleri](AcademicCollector/README.md): `http://localhost:5001` üzerindeki toplama, kalıcı ürün ve okuma işlemleri.
- [Researcher Analysis Service örnekleri](../ResearcherAnalysisService/Requests/README.md): `http://localhost:5011` üzerindeki doğrudan, tam bağlamlı AI işlemleri.

Her `.http` dosyası bağımsız değişkenler içerir. Örnek sırları gerçek değerlerle yalnız yerel ortamda değiştirin; API anahtarı, T.C. kimlik numarası veya başka bir sırrı repoya kaydetmeyin.
